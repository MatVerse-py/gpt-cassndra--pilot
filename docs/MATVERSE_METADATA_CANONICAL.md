## Constitutional line

Authorship and responsibility are exclusively human/institutional. AI systems, agents, assistants, models, automations and tools are not authors, maintainers, owners, contributors, responsible parties or documentation authorities. They may only be used as auxiliary tooling without public authorship attribution.

## Mandatory scan before release

```bash
grep -RIn --exclude-dir=.git \
  -e 'Author: MiniMax Agent' \
  -e 'Author: ChatGPT' \
  -e 'Author: Claude' \
  -e 'Author: Gemini' \
  -e 'Author: AI Agent' \
  -e 'Generated by' \
  -e 'Maintained by AI' \
  -e 'Documentation by AI' \
  .
```

```text
<empty>
```
