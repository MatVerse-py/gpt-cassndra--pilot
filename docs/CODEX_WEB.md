# Diretriz de Propriedade MatVerse com Cassandra Agent

Este repositório passa a operar sob a diretriz de **propriedade institucional MatVerse**, com coordenação operacional via **Cassandra Agent** como camada de orquestração humano-sistema.

## Objetivo da conversão

- Alinhar artefatos, fluxos e documentação ao programa MatVerse.
- Definir o Cassandra Agent como interface de orquestração entre intenção humana, execução técnica e governança.
- Reforçar a política de autoria e responsabilidade humana/institucional nos outputs do sistema.

## Política operacional

1. **Propriedade MatVerse**: o sistema e seus artefatos devem ser tratados como componentes do ecossistema MatVerse.
2. **Orquestração Cassandra**: decisões de fluxo e integração devem seguir o modelo descrito em `docs/CASSANDRA_TOTALITY.md`.
3. **Governança e metadados**: documentos e pacotes devem seguir as regras de `docs/MATVERSE_METADATA_CANONICAL.md`.
4. **Autoria responsável**: agentes de IA atuam como ferramental auxiliar, sem atribuição de autoria, posse ou responsabilidade institucional.
